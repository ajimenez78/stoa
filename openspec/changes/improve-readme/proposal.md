## Why

The current README.md is very brief and does not properly convey the vision, features, and core mechanics of Stoa as detailed in the Game Design Document (GDD.md). Since the game is localized in Spanish but the project is hosted publicly, we need a high-quality, comprehensive English README that acts as the entry point, references the GDD, and retains all existing information.

## What Changes

- Rewrite `README.md` completely in English with modern, visually appealing, and professional formatting.
- Explicitly clarify that while the documentation is in English, the game's language and content are located in Spanish.
- Reference the `GDD.md` document for detailed design, mechanics, narrative, and progression systems.
- Preserve all existing links and references:
  - Expanding content guide link: `Dungeons/Minigames/README.md`
  - Daily practices & weekly challenges JSON: `Dungeons/gym_missions.json`
  - Philosopher quotes JSON: `Dungeons/quotes.json`
  - Third-party music attribution and `CREDITS.md` link.
